## Reporting a Vulnerability
At Altexera, we take security seriously. If you discover a vulnerability in our smart contract, please report it privately.

Please do not create a public GitHub issue. Instead, contact the lead auditor directly via Telegram: [@moritz_sec](https://t.me/moritz_sec) or via email at moritz.schneider.sec@proton.me.

We will acknowledge your report within 24 hours and provide a timeline for a fix.
