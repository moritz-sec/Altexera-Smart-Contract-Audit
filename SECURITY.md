# Security Policy

## Supported Versions

The following versions of the Altexera Smart Contract are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

This repository is maintained for independent security review. If you discover a potential vulnerability in the provided source code, please report it privately.

**Do not** create a public GitHub issue for security-related matters.

### Contact Information
*   **Telegram:** [@moritz_sec](https://t.me/moritz_sec)
*   **Email:** moritz.schneider.sec@proton.me

### Scope of Review
Please note that this repository contains pre-deployment source code. The economic model, third-party protocol risks (Aave, Chainlink, PancakeSwap), and deployed bytecode verification are outside the scope of this specific audit (see `README.md` for full limitations).

## Disclosure Policy

Once a vulnerability report is received and verified, the following steps will be taken:
1.  Confirmation of receipt.
2.  Investigation and reproduction of the reported issue.
3.  Development of a fix or mitigation strategy (if applicable).
4.  Public disclosure (if necessary) after the issue has been addressed.
